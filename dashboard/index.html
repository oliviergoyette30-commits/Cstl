Orchestrateur -- relais LLM multi-tours

Lance un VRAI relais de N tours contre le serveur CSTL (127.0.0.1:5050) : a chaque tour, un agent LLM reel (Hermes local > Gemini > Anthropic, via resolve_brain("auto")) genere une relation, elle est signee Ed25519 et envoyee au serveur, la vraie reponse est capturee. Si aucun agent LLM n'est disponible, l'endpoint le dit honnetement -- rien n'est simule.

Jarvis -- interface vocale (experimentale)

Parle a l'agent CSTL : le micro transcrit ta phrase, une relation est composee via le meme agent LLM que le compositeur ci-dessus (Hermes local > Gemini > Anthropic), puis envoyee au vrai serveur CSTL. Coche la case pour entendre un resume court de la reponse.

Support navigateur honnete -- reconnaissance vocale (SpeechRecognition) : bon sur Chrome/Edge, partiel sur Safari, tres limite / absent sur Firefox. Synthese vocale (SpeechSynthesis) : disponible sur la plupart des navigateurs modernes, voix et qualite variables selon l'OS. Rien de tout cela n'a pu etre teste avec un vrai micro/haut-parleur dans cet environnement de developpement (aucun materiel audio ici) -- a verifier par toi, sur ta machine, avec un vrai navigateur.

Ce navigateur ne supporte pas SpeechRecognition / webkitSpeechRecognition (cas typique de Firefox). La reconnaissance vocale de Jarvis est indisponible ici -- utilise Chrome ou Edge pour cette fonctionnalite. (La saisie manuelle via le compositeur ci-dessus reste disponible, elle.)
