
**Replace with:**
```
## **Règle 4 — Temps orienté (v3.0.1)**

Deux niveaux de scope temporel coexistent et ne doivent pas être confondus :

1. **Ancrage temporel d'énonciation** — propriété du payload entier,
   exprimée via l'en-tête global [TIME] : past | present | future | entangled.

2. **Ordre relatif entre événements** — propriété locale entre deux relations
   d'un même payload, exprimée via les opérateurs « (précède), = (simultané),
   » (suit), «=» (intriqué).

Un payload peut légitimement porter [TIME]: past ET utiliser « = » »
à l'intérieur pour ordonner ses événements passés entre eux.
```

## What is NOT changed

- The 65-symbol semantic alphabet (count unchanged).
- The 121-token syntactic grammar (count unchanged).
- Theorem 1 (k=9 uniqueness) — the archeological layer still occupies
  position 9 of the gene; the `[TIME]` header is a scope-level marker, not
  an encoding position.
- Compression ratios observed in E1 — no byte-level change.

## Impact on downstream tools

- Parsers that silently ignored unknown `[X]` headers: no change needed.
- Strict parsers: add `TIME` to the known-headers list.
- Encoders (LLM prompts): update to mention `[TIME]` as an available scope
  header (see `experiments/e3_expressivity.py` for an example).
