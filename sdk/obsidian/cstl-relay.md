# CSTL Relay Plugin Template

Obsidian plugin template for Couche 6 (Graphify/Obsidian UI Connection) integration.

This plugin enables real-time synchronization of CSTL agent graphs into Obsidian vaults.

## Installation

1. Copy this directory to `.obsidian/plugins/cstl-relay/`
2. Run `npm install` in the plugin directory
3. Enable plugin in Obsidian Settings > Community Plugins > CSTL Relay

## Configuration

Add to `CSTL_Config.md` in your vault:

```yaml
---
CSTL_Version: 5.1.0
CSTL_Host: 127.0.0.1
CSTL_Port: 5050
Obsidian_Sync_Interval: 30000  # milliseconds
Graph_Export_Path: CSTL_Graphs/current.json
---
```

## Features

### Embedded Agent State Display

The plugin provides a code block processor for displaying live agent state:

\`\`\`cstl-agent
agent_name: alice
show_capabilities: true
show_relays: true
show_trust_score: true
\`\`\`

Renders as an interactive card showing:
- Agent name and version
- Public key (hex truncated)
- Trust score with visual indicator
- List of capabilities with wikilinks
- Incoming/outgoing relay connections
- Last sync timestamp

### Auto-sync on Events

When CSTL server emits:
- `agent_register` → Creates/updates agent note
- `relay` with `purpose=dialogue_turn` → Updates relay edges
- `audit_event` → Logs to agent's audit trail section

### Graph Visualization

Obsidian Graph View automatically displays:
- Agent nodes (size = trust_score)
- Capability nodes (color = type)
- Relay edges (thickness = frequency)
- Audit event nodes (shape = event_type)

Enable via: Settings > Graph View > Show CSTL_Agents folder

## Sync Protocol

1. **On Startup**: 
   - Load graph from `CSTL_Graphs/current.json`
   - Render all agent notes
   - Establish WebSocket to CSTL server

2. **On Event** (agent_register, relay, audit):
   - Update graph in memory
   - Write affected agent notes
   - Update graph index
   - Publish to Graph View
   - Save sync timestamp

3. **On Interval** (configurable, default 30s):
   - Re-fetch graph from CSTL HTTP API
   - Diff against cached version
   - Write only changed notes (efficiency)
   - Update statistics dashboard

## REST API Endpoints (from CSTL Server)

Plugin connects to CSTL ADN server (Couche 5c):

- `GET /audit/{case_id}` → Fetch audit trail for agent
- `GET /agents` → List all registered agents
- `GET /graph/export` → Export full graph as JSON
- `POST /graph/import` → Import graph update

## Architecture Mapping

| CSTL Layer | Obsidian Component | Function |
|------------|-------------------|----------|
| Layer 2 | Signature verification badge | Shows signed/unsigned agents |
| Layer 5c | ADN server connection | WebSocket sync source |
| Layer 6 | Plugin + Graph View | Visual agent graph |
| Layer 7 | Agent discovery notes | Agent card display |

## Development Notes

To extend the plugin:

1. **Add new relation type**: Update `EdgeType` enum in `cstl_obsidian_bridge.py`
2. **Custom rendering**: Edit `agent_card_renderer.ts`
3. **New sync event**: Add handler in `cstl_sync_service.ts`

All Python-side changes sync automatically to the plugin via the shared JSON format.

## Known Limitations

- Obsidian Graph View doesn't support weighted edges (relay frequency)
- No real-time 2-way sync (vault → CSTL server not implemented)
- Public keys truncated to 32 chars for readability
