# Archive

Historical material, kept for reference. Nothing here is used by the build,
the tests or the server.

| Folder | Content |
|---|---|
| `reports/` | Session reports, status notes and analyses from September to November 2026. |
| `kappa/` | The kappa agreement experiments (scripts, prompts, results). |
| `samples/` | Old hand-written test payloads and shell scripts. |
| `patches/` | Patches exported from earlier sessions. |
| `dashboard_cstl_os/` | The old local macOS dashboard (CSTL_OS). The current dashboard is served by the server at `/v1/dashboard`. |
| `orchestrator/`, `migrations/`, `sandbox-export/`, `obsidian/` | Earlier prototypes and tool settings. |

The git history keeps every file at its original place.
